The Chainlink Platform (<a href="https://app.chain.link" target="_blank" rel="noopener noreferrer">app.chain.link</a>) is the unified home for Chainlink self-serve products. A single account and organization gives you and your team access to products such as CRE, ACE, CRE Connect, and Data Streams.

## Account and organization management

When you create an account, you either start a new organization (becoming the _Owner_) or join an existing one (becoming a member). To get started, see:

- [Creating an Account](/chainlink-platform/creating-an-account) - Create your account and organization
- [Inviting Team Members](/chainlink-platform/inviting-team-members) - Add members to your organization
- [Understanding Organizations](/chainlink-platform/understanding-organizations) - Learn how organizations work

## Access control

Each member of your organization has a role for each product, and API keys carry the permissions you select for them. To learn more, see:

- [RBAC](/chainlink-platform/rbac) - Role-based access control and what each role can do
- [Assigning and Modifying Roles](/chainlink-platform/assigning-and-modifying-roles) - Change the roles that organization members hold for each product
- <ProductOnly products="cre,ace,crec" block>
    [API Keys](/chainlink-platform/api-keys) - Create and manage API keys for programmatic access
  </ProductOnly>
