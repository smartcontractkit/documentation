Chainlink Local v0.2.7 pins `@chainlink/contracts-ccip` 1.6.2 and `@chainlink/contracts` 1.5.0, and adds the Data Streams billing mechanism toggle in `DataStreamsLocalSimulator`.

## CCIP

These contracts provide Cross-Chain Interoperability Protocol (CCIP) functionality in a local testing environment:

- [CCIPLocalSimulator](/chainlink-local/api-reference/v0.2.7/ccip-local-simulator) - Local CCIP simulator (no-fork mode)
- [CCIPLocalSimulatorFork](/chainlink-local/api-reference/v0.2.7/ccip-local-simulator-fork) - CCIP simulator for forked networks
- [CCIPLocalSimulatorFork JS](/chainlink-local/api-reference/v0.2.7/ccip-local-simulator-fork-js) - JavaScript helpers for fork routing
- [Register](/chainlink-local/api-reference/v0.2.7/register) - CCIP network configuration registry

## Data Streams

Contracts for simulating Chainlink Data Streams:

- [DataStreamsLocalSimulator](/chainlink-local/api-reference/v0.2.7/data-streams-local-simulator) - Local Data Streams simulator (no-fork mode)
- [DataStreamsLocalSimulatorFork](/chainlink-local/api-reference/v0.2.7/data-streams-local-simulator-fork) - Data Streams simulator for forked networks
- [MockVerifier](/chainlink-local/api-reference/v0.2.7/mock-verifier) - Mock Data Streams verifier
- [MockVerifierProxy](/chainlink-local/api-reference/v0.2.7/mock-verifier-proxy) - Mock Data Streams verifier proxy
- [MockReportGenerator](/chainlink-local/api-reference/v0.2.7/mock-report-generator) - Signed report generator for every report schema
- [MockFeeManager](/chainlink-local/api-reference/v0.2.7/mock-fee-manager) - Mock verifier fee manager
- [MockRewardManager](/chainlink-local/api-reference/v0.2.7/mock-reward-manager) - Mock reward manager
- [ReportVersions](/chainlink-local/api-reference/v0.2.7/report-versions) - Data Streams report schemas
- [Register (Data Streams)](/chainlink-local/api-reference/v0.2.7/data-streams-register) - Data Streams network configuration registry

## Data Feeds

Contracts for simulating Chainlink Data Feeds:

- [AggregatorInterface](/chainlink-local/api-reference/v0.2.7/aggregator-interface) - Basic price feed interface
- [AggregatorV2V3Interface](/chainlink-local/api-reference/v0.2.7/aggregator-v2-v3-interface) - Combined V2/V3 price feed interface
- [AggregatorV3Interface](/chainlink-local/api-reference/v0.2.7/aggregator-v3-interface) - Extended price feed interface
- [MockOffchainAggregator](/chainlink-local/api-reference/v0.2.7/mock-offchain-aggregator) - Mock implementation of off-chain aggregator
- [MockV3Aggregator](/chainlink-local/api-reference/v0.2.7/mock-v3-aggregator) - Mock implementation of V3 aggregator

## Token Contracts

Standard token implementations for testing:

- [BurnMintERC677Helper](/chainlink-local/api-reference/v0.2.7/burn-mint-erc677-helper) - Helper contract for ERC677 token operations
- [LinkToken](/chainlink-local/api-reference/v0.2.7/link-token) - LINK token implementation
- [WETH9](/chainlink-local/api-reference/v0.2.7/weth9) - Wrapped Ether implementation
