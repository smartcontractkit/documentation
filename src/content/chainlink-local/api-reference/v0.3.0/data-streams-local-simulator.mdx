### configuration

Returns configuration details for pre-deployed contracts and services needed for
local Data Streams simulations.

```solidity
function configuration()
    public
    view
    returns (
        WETH9 wrappedNative_,
        LinkToken linkToken_,
        MockVerifier mockVerifier_,
        MockVerifierProxy mockVerifierProxy_,
        MockFeeManager mockFeeManager_,
        MockRewardManager mockRewardManager_
    );
```

**Returns**

| Name                 | Type                | Description                                                                       |
| -------------------- | ------------------- | --------------------------------------------------------------------------------- |
| `wrappedNative_`     | `WETH9`             | - The wrapped native token.                                                       |
| `linkToken_`         | `LinkToken`         | - The LINK token.                                                                 |
| `mockVerifier_`      | `MockVerifier`      | - The mock verifier contract.                                                     |
| `mockVerifierProxy_` | `MockVerifierProxy` | - The mock verifier proxy contract.                                               |
| `mockFeeManager_`    | `MockFeeManager`    | - The mock fee manager contract (returns what's currently set on verifier proxy). |
| `mockRewardManager_` | `MockRewardManager` | - The mock reward manager contract (address(0) if fee manager is disabled).       |

### enableOffChainBilling

Enables off-chain billing mechanism by removing fee manager

This simulates chains that don't have FeeManager contracts deployed

```solidity
function enableOffChainBilling() external;
```

### enableOnChainBilling

Enables on-chain billing mechanism by deploying/setting fee manager

This simulates chains that have FeeManager contracts deployed

```solidity
function enableOnChainBilling() external;
```

### getBillingMechanism

Returns the current billing mechanism type

```solidity
function getBillingMechanism() external view returns (string memory billingType);
```

**Returns**

| Name          | Type     | Description                                                   |
| ------------- | -------- | ------------------------------------------------------------- |
| `billingType` | `string` | "on-chain" if fee manager is enabled, "off-chain" if disabled |

### requestLinkFromFaucet

Requests LINK tokens from the faucet. The provided amount of tokens are
transferred to provided destination address.

```solidity
function requestLinkFromFaucet(address to, uint256 amount) external returns (bool success);
```

**Parameters**

| Name     | Type      | Description                                        |
| -------- | --------- | -------------------------------------------------- |
| `to`     | `address` | - The address to which LINK tokens are to be sent. |
| `amount` | `uint256` | - The amount of LINK tokens to send.               |

**Returns**

| Name      | Type   | Description                                                                   |
| --------- | ------ | ----------------------------------------------------------------------------- |
| `success` | `bool` | - Returns `true` if the transfer of tokens was successful, otherwise `false`. |
