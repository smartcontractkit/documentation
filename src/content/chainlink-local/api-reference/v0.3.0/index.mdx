Chainlink Local v0.3.0 (V3) targets CCIP 2.0: `CCIPLocalSimulatorFork` and the Hardhat 3 JavaScript fork helper support CCIP 2.0 (CCV-based) lanes, the local router applies the CCIP 2.0 message rules, and the built-in `Register` network details are split into generated data shards so every generated contract stays under the EIP-170 runtime limit. This is a **breaking** release; Hardhat 2 is not supported in `0.3.x` (see [the release notes](https://github.com/smartcontractkit/chainlink-local/blob/v0.3.0/CHANGELOG.md)).

## CCIP

These contracts provide Cross-Chain Interoperability Protocol (CCIP) functionality in a local testing environment:

- [CCIPLocalSimulator](/chainlink-local/api-reference/v0.3.0/ccip-local-simulator) - Local CCIP simulator (no-fork mode)
- [CCIPLocalSimulatorFork](/chainlink-local/api-reference/v0.3.0/ccip-local-simulator-fork) - CCIP simulator for forked networks
- [CCIPLocalSimulatorFork JS](/chainlink-local/api-reference/v0.3.0/ccip-local-simulator-fork-js) - JavaScript helpers for fork routing
- [Register](/chainlink-local/api-reference/v0.3.0/register) - CCIP network configuration registry
- [CCIPLocalRouter](/chainlink-local/api-reference/v0.3.0/ccip-local-router) - The local-mode router with CCIP 2.0 message rules

## Data Streams

Contracts for simulating Chainlink Data Streams:

- [DataStreamsLocalSimulator](/chainlink-local/api-reference/v0.3.0/data-streams-local-simulator) - Local Data Streams simulator (no-fork mode)
- [DataStreamsLocalSimulatorFork](/chainlink-local/api-reference/v0.3.0/data-streams-local-simulator-fork) - Data Streams simulator for forked networks
- [MockVerifier](/chainlink-local/api-reference/v0.3.0/mock-verifier) - Mock Data Streams verifier
- [MockVerifierProxy](/chainlink-local/api-reference/v0.3.0/mock-verifier-proxy) - Mock Data Streams verifier proxy
- [MockReportGenerator](/chainlink-local/api-reference/v0.3.0/mock-report-generator) - Signed report generator for every report schema
- [MockFeeManager](/chainlink-local/api-reference/v0.3.0/mock-fee-manager) - Mock verifier fee manager
- [MockRewardManager](/chainlink-local/api-reference/v0.3.0/mock-reward-manager) - Mock reward manager
- [ReportVersions](/chainlink-local/api-reference/v0.3.0/report-versions) - Data Streams report schemas
- [Register (Data Streams)](/chainlink-local/api-reference/v0.3.0/data-streams-register) - Data Streams network configuration registry
