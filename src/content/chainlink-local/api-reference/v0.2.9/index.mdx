Chainlink Local v0.2.9 fixes `CCIPLocalSimulatorFork.switchChainAndRouteMessage` to pair the destination OffRamp with the source OnRamp by reading `getSourceChainConfig` (v1.6+) and `getStaticConfig` (pre-v1.6), with a fallback to other OffRamps with the same `sourceChainSelector`. This is the last release of the `0.2.x` line and the one Hardhat 2 users stay on.

## CCIP

These contracts provide Cross-Chain Interoperability Protocol (CCIP) functionality in a local testing environment:

- [CCIPLocalSimulator](/chainlink-local/api-reference/v0.2.9/ccip-local-simulator) - Local CCIP simulator (no-fork mode)
- [CCIPLocalSimulatorFork](/chainlink-local/api-reference/v0.2.9/ccip-local-simulator-fork) - CCIP simulator for forked networks
- [CCIPLocalSimulatorFork JS](/chainlink-local/api-reference/v0.2.9/ccip-local-simulator-fork-js) - JavaScript helpers for fork routing
- [Register](/chainlink-local/api-reference/v0.2.9/register) - CCIP network configuration registry

## Data Streams

Contracts for simulating Chainlink Data Streams:

- [DataStreamsLocalSimulator](/chainlink-local/api-reference/v0.2.9/data-streams-local-simulator) - Local Data Streams simulator (no-fork mode)
- [DataStreamsLocalSimulatorFork](/chainlink-local/api-reference/v0.2.9/data-streams-local-simulator-fork) - Data Streams simulator for forked networks
- [MockVerifier](/chainlink-local/api-reference/v0.2.9/mock-verifier) - Mock Data Streams verifier
- [MockVerifierProxy](/chainlink-local/api-reference/v0.2.9/mock-verifier-proxy) - Mock Data Streams verifier proxy
- [MockReportGenerator](/chainlink-local/api-reference/v0.2.9/mock-report-generator) - Signed report generator for every report schema
- [MockFeeManager](/chainlink-local/api-reference/v0.2.9/mock-fee-manager) - Mock verifier fee manager
- [MockRewardManager](/chainlink-local/api-reference/v0.2.9/mock-reward-manager) - Mock reward manager
- [ReportVersions](/chainlink-local/api-reference/v0.2.9/report-versions) - Data Streams report schemas
- [Register (Data Streams)](/chainlink-local/api-reference/v0.2.9/data-streams-register) - Data Streams network configuration registry
