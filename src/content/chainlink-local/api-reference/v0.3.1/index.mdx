Chainlink Local v0.3.1 (V3) targets CCIP 2.0: it pins `@chainlink/contracts-ccip` 2.0.0 and `@chainlink/contracts` 1.5.0, and the local router applies the CCIP 2.0 OnRamp and OffRamp message rules. Fork routing supports every CCIP era (pre-1.6, 1.6 and CCIP 2.0). Hardhat 2 is not supported in `0.3.x`; Hardhat 2 users stay on `0.2.x` (see [the release notes](https://github.com/smartcontractkit/chainlink-local/blob/v0.3.1/CHANGELOG.md)).

## CCIP

These contracts provide Cross-Chain Interoperability Protocol (CCIP) functionality in a local testing environment:

- [CCIPLocalSimulator](/chainlink-local/api-reference/v0.3.1/ccip-local-simulator) - Local CCIP simulator (no-fork mode)
- [CCIPLocalRouter](/chainlink-local/api-reference/v0.3.1/ccip-local-router) - The local-mode router with CCIP 2.0 message rules
- [CCIPLocalSimulatorFork](/chainlink-local/api-reference/v0.3.1/ccip-local-simulator-fork) - CCIP simulator for forked networks (all CCIP eras)
- [CCIPLocalSimulatorFork JS](/chainlink-local/api-reference/v0.3.1/ccip-local-simulator-fork-js) - Hardhat 3 JavaScript helpers for fork routing
- [Register](/chainlink-local/api-reference/v0.3.1/register) - CCIP network configuration registry

## Data Streams

Contracts for simulating Chainlink Data Streams:

- [DataStreamsLocalSimulator](/chainlink-local/api-reference/v0.3.1/data-streams-local-simulator) - Local Data Streams simulator (no-fork mode)
- [DataStreamsLocalSimulatorFork](/chainlink-local/api-reference/v0.3.1/data-streams-local-simulator-fork) - Data Streams simulator for forked networks
- [MockVerifier](/chainlink-local/api-reference/v0.3.1/mock-verifier) - Mock Data Streams verifier
- [MockVerifierProxy](/chainlink-local/api-reference/v0.3.1/mock-verifier-proxy) - Mock Data Streams verifier proxy
- [MockReportGenerator](/chainlink-local/api-reference/v0.3.1/mock-report-generator) - Signed report generator for every report schema
- [MockFeeManager](/chainlink-local/api-reference/v0.3.1/mock-fee-manager) - Mock verifier fee manager
- [MockRewardManager](/chainlink-local/api-reference/v0.3.1/mock-reward-manager) - Mock reward manager
- [ReportVersions](/chainlink-local/api-reference/v0.3.1/report-versions) - Data Streams report schemas (`ReportV1`-`ReportV13`)
- [Register (Data Streams)](/chainlink-local/api-reference/v0.3.1/data-streams-register) - Data Streams network configuration registry

Contracts for simulating Chainlink Data Feeds:

- [AggregatorV3Interface](/chainlink-local/api-reference/v0.3.1/aggregator-v3-interface) - Extended price feed interface

- [MockV3Aggregator](/chainlink-local/api-reference/v0.3.1/mock-v3-aggregator) - Mock implementation of V3 aggregator
