## MockVerifier

A mock implementation of the Data Streams verifier for local testing.

[`MockVerifier`](https://github.com/smartcontractkit/chainlink-local/blob/v0.3.1/src/data-streams/MockVerifier.sol)

<Aside>
  This contract verifies reports signed by the mock DON address (generated from `keccak256("Mock Data Streams DON")`).
  Only the [`MockVerifierProxy`](/chainlink-local/api-reference/v0.3.1/mock-verifier-proxy) may call `verify`. Reports
  are generated with [`MockReportGenerator`](/chainlink-local/api-reference/v0.3.1/mock-report-generator).
</Aside>

### verify

Verifies a signed report and returns the report data.

```solidity
function verify(bytes calldata signedReport, address sender) external returns (bytes memory verifierResponse)
```

<Aside>
  Only callable by the verifier proxy. Decodes the signed report, checks the feed and config digest are active, recovers
  the signer with `ecrecover` and marks the signature as used. Returns the report data.
</Aside>

#### Parameters

| Parameter    | Type      | Description                           |
| ------------ | --------- | ------------------------------------- |
| signedReport | `bytes`   | The ABI-encoded signed report         |
| sender       | `address` | The address that submitted the report |

#### Returns

| Parameter        | Type    | Description             |
| ---------------- | ------- | ----------------------- |
| verifierResponse | `bytes` | The decoded report data |
