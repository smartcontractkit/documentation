This section explains the Cross-Chain Token (CCT) standard, a Chainlink CCIP feature for cross-chain token transfers.

Learn how token pools (lock/release and burn/mint) operate, what token issuers configure for production, how `AdvancedPoolHooks` adds transfer controls to a token pool, how token pool rate limits bound cross-chain flow, and how to migrate token pools from v1.x to v2.0.
