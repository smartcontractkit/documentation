## Summary

`RegistryModuleOwnerCustom` is a registry module used by `[TokenAdminRegistry](/ccip/evm/api-reference/v2.0.0/token-admin-registry)` to enable token-level administrators to self-register without registry owner intervention.

It supports three authority discovery mechanisms:

1. `getCCIPAdmin()` via `[IGetCCIPAdmin](/ccip/evm/api-reference/v2.0.0/i-get-ccip-admin)`
2. `owner()` via `[IOwner](/ccip/evm/api-reference/v2.0.0/i-owner)`
3. OpenZeppelin `AccessControl` with `DEFAULT_ADMIN_ROLE`

The module proposes administrators in `TokenAdminRegistry`, but does not finalize the two-step transfer.

## External API

### registerAdminViaGetCCIPAdmin

```solidity id="et1iz8"
function registerAdminViaGetCCIPAdmin(address token)
  external
```

Flow:

1. Calls `IGetCCIPAdmin(token).getCCIPAdmin()`.
2. Calls `_registerAdmin(token, derivedAdmin)`.

Reverts `CanOnlySelfRegister(derivedAdmin, token)` if `derivedAdmin != msg.sender`.

---

### registerAdminViaOwner

```solidity id="yzv7yx"
function registerAdminViaOwner(address token)
  external
```

Flow:

1. Calls `IOwner(token).owner()`.
2. Calls `_registerAdmin(token, derivedAdmin)`.

Reverts `CanOnlySelfRegister(derivedAdmin, token)` if mismatch.

---

### registerAccessControlDefaultAdmin

```solidity id="mb9v8d"
function registerAccessControlDefaultAdmin(address token)
  external
```

Flow:

1. Reads:

```solidity id="b3kq78"
bytes32 role = AccessControl(token).DEFAULT_ADMIN_ROLE();
```

2. Validates:

```solidity id="v8emna"
AccessControl(token).hasRole(role, msg.sender)
```

Else reverts:

```solidity id="f87n3v"
error RequiredRoleNotFound(address msgSender, bytes32 role, address token);
```

3. Calls `_registerAdmin(token, msg.sender)`.

## Security model

- Self-registration only: caller must match derived admin.
- Does not bypass `TokenAdminRegistry` ownership rules.
- Two-step admin transfer still required via `acceptAdminRole`.
- Does not permit registry owner override via this module.
- Token contract determines authoritative admin source.
