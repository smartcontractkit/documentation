## Summary

`CREATE2Factory` enables deterministic contract deployment using the EVM `CREATE2` opcode.

Capabilities:

1. Deploy contracts at predictable addresses.
2. Optionally execute post-deployment calls.
3. Restrict deployment to an owner-managed allowlist.
4. Compute deterministic addresses prior to deployment.

To preserve cross-chain address parity, this factory must be deployed at identical addresses across chains.

## Deployment API

### createAndCall

```solidity
function createAndCall(
  bytes calldata creationCode,
  bytes32 salt,
  bytes[] memory calls
) external returns (address)
```

Behavior:

1. Reverts `CallerNotAllowed(msg.sender)` if caller not in `s_allowList`.
2. Deploys contract:

```solidity
address contractAddress =
  Create2.deploy(0, salt, creationCode);
```

3. Emits:

```solidity
event ContractDeployed(address indexed contractAddress);
```

4. Iterates through `calls` and executes:

```solidity
(bool success, bytes memory result) =
  contractAddress.call(calls[i]);
```

5. Reverts:

```solidity
error CallFailed(uint256 index, bytes result);
```

If any call fails.

Returns deployed contract address.

## Internal Functions

### \_applyAllowListUpdates

```solidity
function _applyAllowListUpdates(
  address[] memory removes,
  address[] memory adds
) internal
```

Behavior:

1. Iterates `removes`:
   - If removed, emits `CallerRemoved(address)`.

2. Iterates `adds`:
   - If added, emits `CallerAdded(address)`.

## Security model

- Only allowlisted callers may deploy.
- Owner controls allowlist.
- Uses `call`, not `delegatecall`, for post-deployment execution.
- Deploys with zero ETH.
- Deterministic address derived from:
  - Factory address
  - `salt`
  - `keccak256(creationCode)`
