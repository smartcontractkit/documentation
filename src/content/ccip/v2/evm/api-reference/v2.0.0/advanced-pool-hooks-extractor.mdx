## Summary

`AdvancedPoolHooksExtractor` implements `IExtractor` and transforms `AdvancedPoolHooks` calldata into a canonical list of `IPolicyEngine.Parameter` entries.

It is:

- Deterministic
- Pure
- Read-only
- Stateless

This contract does not modify state and is safe for on-chain policy evaluation paths.

## External API

### `extract`

```solidity
function extract(IPolicyEngine.Payload calldata payload)
  public
  pure
  virtual
  returns (IPolicyEngine.Parameter[] memory)
```

Behavior:

- Routes based on `payload.selector`:
  - If equal to `IAdvancedPoolHooks.preflightCheck.selector`
    → calls `_extractPreflightCheck`.

  - If equal to `IAdvancedPoolHooks.postflightCheck.selector`
    → calls `_extractPostflightCheck`.

  - Otherwise reverts:

```solidity
IPolicyEngine.UnsupportedSelector(payload.selector)
```

Returns an array of extracted `IPolicyEngine.Parameter`.

## Internal Functions

### `_extractPreflightCheck`

```solidity
function _extractPreflightCheck(IPolicyEngine.Payload calldata payload)
  internal
  pure
  returns (IPolicyEngine.Parameter[] memory)
```

Decodes `payload.data` as:

```solidity
(Pool.LockOrBurnInV1, uint16 blockConfirmationRequested, bytes tokenArgs, uint256 amountPostFee)
```

Builds and returns 7 parameters:

- `PARAM_FROM` → original sender
- `PARAM_TO` → receiver (raw bytes)
- `PARAM_AMOUNT` → amount
- `PARAM_AMOUNT_POST_FEE` → amountPostFee
- `PARAM_REMOTE_CHAIN_SELECTOR` → remoteChainSelector
- `PARAM_TOKEN` → localToken
- `PARAM_BLOCK_CONFIRMATION_REQUESTED` → blockConfirmationRequested

`tokenArgs` is intentionally skipped.

---

### `_extractPostflightCheck`

```solidity
function _extractPostflightCheck(IPolicyEngine.Payload calldata payload)
  internal
  pure
  returns (IPolicyEngine.Parameter[] memory)
```

Decodes `payload.data` as:

```solidity
(Pool.ReleaseOrMintInV1, uint256 localAmount, uint16 blockConfirmationRequested)
```

Builds and returns 9 parameters:

- `PARAM_FROM` → original sender
- `PARAM_TO` → encoded receiver
- `PARAM_AMOUNT` → localAmount
- `PARAM_REMOTE_CHAIN_SELECTOR` → remoteChainSelector
- `PARAM_TOKEN` → localToken
- `PARAM_BLOCK_CONFIRMATION_REQUESTED` → blockConfirmationRequested
- `PARAM_SOURCE_POOL_ADDRESS` → sourcePoolAddress
- `PARAM_SOURCE_POOL_DATA` → sourcePoolData
- `PARAM_SOURCE_DENOMINATED_AMOUNT` → sourceDenominatedAmount

`offchainTokenData` is treated as contextual input and skipped.

- Safe to invoke from policy evaluation paths.
- Selector-based routing prevents accidental mis-decoding.
