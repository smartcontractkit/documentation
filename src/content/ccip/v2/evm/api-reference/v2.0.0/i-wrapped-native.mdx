## Summary

`IWrappedNative` defines the minimal interface for wrapped native tokens (e.g., WETH, WBNB, WMATIC).

It extends `IERC20` and adds methods to:

- Wrap native currency into ERC20 form (`deposit`)
- Unwrap ERC20 tokens back into native currency (`withdraw`)

## Interface surface

```solidity
interface IWrappedNative is IERC20 {
```

---

### deposit

```solidity
function deposit() external payable;
```

Wraps native currency into ERC20 tokens.

---

### withdraw

```solidity
function withdraw(uint256 wad) external;
```

Unwraps wrapped tokens into native currency.

---

```solidity
}
```

---

## Integration notes / expectations

- `deposit()` must be called with a non-zero `msg.value`.
- `withdraw(uint256 wad)` burns wrapped tokens and transfers native currency.
- Implementations must handle native token transfers safely.
- Consumers treat wrapped native tokens as standard ERC20 tokens with optional wrapping functionality.
