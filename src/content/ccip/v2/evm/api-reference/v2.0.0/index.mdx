## Available Versions

### Latest Release

- **CCIP v2.0.0** (Current Version)

  Major architectural upgrades:
  - Modular Cross-Chain Verifier (CCV) system
  - Versioned verifier resolution via `VersionedVerifierResolver`
  - USDC/CCTP integration via dedicated pool and transmitter proxy contracts
  - Lombard bridge integration via dedicated verifier and pool
  - Siloed lock-release liquidity model
  - AdvancedPoolHooks support for pool policy/allowlist extensions
  - Signature quorum validation components
  - RMN safety gating via `RMNRemote` and `RMNProxy`
  - Unified burn/mint and lock/release abstractions across pools

  Breaking changes from v1.x:
  - Verifier logic extracted from `OffRamp` into dedicated CCV contracts
  - Pool extensibility standardized through internal hooks
  - Cross-chain fee modeling expanded for verifier-specific execution
