## Summary

`RMN` is the Risk Management Network contract. It maintains curse state for subjects, which CCIP contracts check to gate message and token flows.

It implements `[IRMN](/ccip/evm/api-reference/v2.0.0/i-rmn)`. Pools and ramps call `isCursed` before processing; a live curse halts the affected flows until the subject is uncursed.

## Global curse subject

```solidity
bytes16 constant GLOBAL_CURSE_SUBJECT = 0x01000000000000000000000000000001;
```

A curse on this subject makes both `isCursed()` and `isCursed(bytes16)` return true. Use it for issues affecting all CCIP chains or the chain this contract is deployed on, instead of the local chain selector.

## External API

### curse

```solidity
function curse(bytes16 subject) external
function curse(bytes16[] memory subjects) public
```

Curses one subject or an array of subjects. Callable by the owner or an authorized caller.

Already-cursed subjects, including duplicates within the array, are silently skipped so a single redundant entry does not block the remaining subjects. Emits `Cursed` with only the newly cursed subjects, and emits nothing if every entry was already cursed.

---

### uncurse

```solidity
function uncurse(bytes16 subject) external
function uncurse(bytes16[] memory subjects) public onlyOwner
```

Uncurses one subject or an array of subjects. Owner-only.

Reverts `NotCursed(subject)` if any subject in the array is not cursed. Emits `Uncursed` with the subjects.

---

### getCursedSubjects

```solidity
function getCursedSubjects() external view returns (bytes16[] memory subjects)
```

Returns the current set of cursed subjects.

---

### isCursed

```solidity
function isCursed() external view returns (bool)
function isCursed(bytes16 subject) external view returns (bool)
```

The no-argument overload returns true only if the global curse subject is active.

The subject overload returns true if the given subject is cursed or the global curse subject is active. To check whether a particular chain is cursed, pass `bytes16(uint128(chainSelector))`.

Both overloads return false immediately when no subjects are cursed at all.
