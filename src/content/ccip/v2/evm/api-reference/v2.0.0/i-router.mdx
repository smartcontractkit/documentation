## Summary

`IRouter` defines the minimal interface for the CCIP [Router](/ccip/evm/api-reference/v2.0.0/router).

It is used by:

- [OffRamp](/ccip/evm/api-reference/v2.0.0/offramp) contracts to route verified messages to receivers.
- Pools and verifiers to validate configured ramps.
- Integrations that query routing configuration.

## Integration notes / expectations

- `routeMessage` must only be callable by configured off-ramps.
- `getOnRamp` and `isOffRamp` are used for ramp authorization checks.
- Implementations are expected to enforce strict caller validation internally.
