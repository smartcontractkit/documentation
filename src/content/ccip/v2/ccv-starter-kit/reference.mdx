## On-chain contracts kit

The kit is documented as a book:
[getting started](https://github.com/smartcontractkit/chainlink-ccv-starter-kit-contracts/blob/main/docs/src/getting-started.md),
[deploy](https://github.com/smartcontractkit/chainlink-ccv-starter-kit-contracts/blob/main/docs/src/deploy.md),
[configure](https://github.com/smartcontractkit/chainlink-ccv-starter-kit-contracts/blob/main/docs/src/configure.md),
[governance](https://github.com/smartcontractkit/chainlink-ccv-starter-kit-contracts/blob/main/docs/src/governance.md),
[operations](https://github.com/smartcontractkit/chainlink-ccv-starter-kit-contracts/blob/main/docs/src/operations.md),
and
[safe batches](https://github.com/smartcontractkit/chainlink-ccv-starter-kit-contracts/blob/main/docs/src/safe-batches.md).

Every `make` target, its caller, and its mode are in the
[command reference](https://github.com/smartcontractkit/chainlink-ccv-starter-kit-contracts/blob/main/docs/src/commands.md),
with the
[config sync commands](https://github.com/smartcontractkit/chainlink-ccv-starter-kit-contracts/blob/main/docs/src/config-sync-reference.md)
alongside it. Both are generated from the Makefile and gated in CI, so they stay in step with the targets.

## Off-chain kit

The `ccv-cell` Helm chart is documented in its
[deployment runbook](https://github.com/smartcontractkit/chainlink-ccv-starter-kit/blob/main/RUNBOOK.md) and
[chart values reference](https://github.com/smartcontractkit/chainlink-ccv-starter-kit/blob/main/charts/ccv-cell/README.md).
It runs two Docker images, the verifier and the aggregator, published to the public Amazon ECR gallery
([verifier](https://gallery.ecr.aws/chainlink/chainlink-ccv-verifier),
[aggregator](https://gallery.ecr.aws/chainlink/chainlink-ccv-aggregator)), where you can see the available
versions; the [chart releases](https://github.com/smartcontractkit/chainlink-ccv-starter-kit/releases) are on
GitHub. The chart sets a default image tag; override it in your chart values to run a specific version.
