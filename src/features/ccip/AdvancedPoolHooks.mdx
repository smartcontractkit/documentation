<Aside type="note" title="What are advanced pool hooks?">
  [Advanced Pool
  Hooks](https://github.com/smartcontractkit/chainlink-ccip/tree/contracts-ccip-v2.0.0/chains/evm/contracts/pools/AdvancedPoolHooks.sol)
  are an optional security layer you can attach to a token pool. They run checks:
  <ol>
    <li>**before** tokens are locked/burned (source chain)</li>
    <li>**before** tokens are released/minted (destination chain)</li>
  </ol>
  Most deployments do **not** need a hook. You would attach one only if you want to:
  <ul>
    <li>Make it so that only certain addresses can transfer your token cross-chain.</li>
    <li>Put in place additional checks for large transfers above a threshold amount.</li>
    <li>Plug in an external policy engine for custom compliance checks.</li>
  </ul>
</Aside>
