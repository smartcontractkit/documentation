<Aside type="caution" title="Chainlink VRF v2 is deprecated">
  Security fixes for VRF v2 are not guaranteed. VRF v2.5 replaced both VRF v1 and VRF v2 on November 29, 2024. [Migrate
  your application to Chainlink VRF v2.5](/vrf/v2-5/migration-from-v2).

The migration guide includes VRF v2.5 code examples for both subscription and direct funding and explains the
differences between VRF v2.5 and VRF v2.

</Aside>
